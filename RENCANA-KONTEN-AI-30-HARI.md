## 3. Aturan Operasional Produksi Harian (`/daily`)

Setiap eksekusi harian wajib mengikuti urutan:
1. Panggil judul artikel sesuai nomor urut kalender di atas.
2. Lakukan riset semantik dan knowledge graph sesuai protokol `pakar-entity-seo`.
3. Tulis draf artikel sesuai standar `penulis-ahli` (Humanizer + GEO 2026 + Non-Komoditas Batam).
4. Pastikan frontmatter memiliki array `faq` (5-6 butir) dan minimal 2 internal link.
5. Daftarkan URL artikel baru ke `src/utils/internalLinks.ts`, `SUMBER-PENGETAHUAN.md`, dan perbarui status di file ini.
6. Jalankan `npm run build` dan verifikasi exit code 0.
